# triKDev — Portfolio

Portfolio de **KODO Koffi Kévin** — Développeur Full-Stack Web & Mobile Junior.

## Live
https://trikdev-portofolio.netlify.app

## Structure
- `index.html` + `script/index.js` — site public (données dynamiques)
- `data/content.json` — **source de vérité** (projets, expériences, compétences, contact…)
- `admin/` — backoffice responsive
- `img/` — médias (photo, logo, CV)

## Backoffice
1. Ouvre `/admin/`
2. Mot de passe par défaut : `trikdev2026` (modifiable dans Réglages)
3. Édite profil, contact, compétences, formations, expériences, projets
4. **Sauver brouillon** → prévisualisation immédiate (même navigateur)
5. **Exporter JSON** → remplace `data/content.json` sur GitHub → redeploy Netlify

## Stack
HTML · CSS · JavaScript · Tailwind CDN · Lucide
